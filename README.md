# ReTune

Oficial repo to get &amp; install ReTune, a lightweight and stylish YouTube Music client for Android.

## Features

- Play songs from YT/YT Music without ads
- YouTube-Music synchronization
- Importing from Spotify
- Background playback
- Search songs, videos, albums, and playlists from YouTube Music
- Login support
- Cache and download songs for offline playback
- Synchronized lyrics
- Lyrics translator
- Skip silence
- Audio normalization
- Adjust tempo/pitch
- Dynamic theme
- Android Auto support
- Personalized quick picks
